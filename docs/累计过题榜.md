# 累计过题榜

排行榜顺序：签到榜、Rating 榜、过题榜、财富榜。总览仍只展示本人，完整榜单仅展示当前团队的活跃成员，排除系统管理员。

累计数按用户保存，不按学期或团队清零。比赛 AC 与提交题目是两个独立来源，分别去重后相加；同一题在两个来源都有记录时分别计数。

- 比赛来源：已绑定账号同步得到的 `accepted=True` 题号，按平台、比赛编号、题号去重，不依赖奖励领取或奖励起始日期。演示记录不计入。同步入库时将 AC 证据保存到 `SolvedProblemCredit`，后续解绑或清理同步记录不撤销已累计结果。
- 提交来源：有效且通过截图审核的提交，按题目规范化 identity 去重。现存提交被删除或退回时不计入；学期清理/删除前将仍有效的题目写入永久记录，之后清除原始材料不会清零。永久记录与新提交按题目去重。

`SolvedProblemCredit` 仅关联用户，不关联学期、成员关系或比赛进度，具有用户、来源、题目键的唯一约束。删除用户账号时随账号删除。
