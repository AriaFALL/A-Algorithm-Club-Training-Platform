# 管理工作台：系统备份、恢复与改密

仅系统管理员可访问。团队管理员和普通成员没有相关接口权限。

## 备份

在管理工作台的“备份与恢复”中点击“创建完整备份”。任务在独立进程执行，页面持续显示结果，完成后可下载ZIP、恢复或删除该份备份。

内容包括所有Django业务表、账号密码哈希、平台配置（已加密凭据）、题库、比赛进度、RBC余额/流水/领取凭证及整个上传目录。不包括登录会话、程序源码、数据库结构迁移操作、Redis队列、`.env`和Django密钥。恢复前后程序数据库迁移版本必须一致；必须保留原来的`DJANGO_SECRET_KEY`，否则备份签名及原有加密配置无法使用。

备份位于独立的`backup_data` Docker卷（容器`/app/backups/system`），不通过公开媒体路径访问；Web/Worker/Beat共享操作代次标记。仅管理员可下载，响应禁止缓存。文件含敏感资料，ZIP本身未加密，下载后请存放在可信位置。外部迁移时需同时安全迁移原有环境配置及密钥。此格式与旧命令行SQL/pg_dump备份格式不同，不能把SQL备份改名ZIP后导入。

## 恢复

1. 在列表选择一份备份；如文件在本地，先“上传并校验”，通过后才进入列表。
2. 点击“恢复”，填写当前管理员密码，并输入“恢复全部数据”确认。
3. 程序先校验签名、数据库迁移版本、文件清单、路径、逐文件大小与SHA256，并检查剩余空间。校验失败不修改业务数据。
4. 校验通过后自动创建“恢复前自动安全备份”，再恢复数据库与上传文件。正常错误会回滚数据库及文件更换，安全备份保留。
5. 完成后所有登录会话清除，页面跳转登录页。使用**备份时的账号密码**登录；RBC余额、历史及系统配置也恢复为该时间点。

备份/恢复期间使用数据库协调锁暂停API访问和后台任务执行；页面静态资源及仅查询进度的操作令牌接口仍可用。锁等待最多30秒，长任务未结束则本次操作失败，可稍后重试。进度接口使用仅启动者拿到的随机UUID令牌，不返回业务记录或凭据；恢复后即使会话失效仍能显示完成结果。

恢复会改变任务代次，丢弃恢复前排队的旧任务。快照中未完成的比赛同步和题名解析改为可重试失败，正在执行的清理任务重新排队，避免永久“处理中”。周期日程任务仍按原时间执行。

独立进程日志位于备份目录的`operation-<编号>.log`。服务意外断电/进程被强杀不等同于可捕获的普通错误：可能需要用自动安全备份再次恢复，并检查上传目录中`.restore-rollback-<编号>`保留的原文件。不要在恢复过程中强制删除容器、磁盘文件或备份卷。备份应定期下载到独立位置，单机卷不能抵御整机磁盘丢失。

## 管理员修改密码

在“修改管理员密码”中填写当前密码、新密码及确认密码。后端锁定账号并保存，事务完成后重新读取数据库核验新密码；确认成功才退出当前登录并返回成功。页面跳转登录页，显示保存完成提示。旧密码不可登录，其他已有会话因密码认证哈希改变也会失效。

错误旧密码、两次密码不一致或保存失败，不按成功流程退出。普通成员个人页的改密仍保留当前会话；系统管理员即使调用个人页密码接口，也使用强制退出规则。本次功能部署不替用户更改当前管理员密码。
